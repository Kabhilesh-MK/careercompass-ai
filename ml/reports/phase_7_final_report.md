## 9. Data Integrity

- **No Fake Percentages**: Removed static `'86%'`, `'67%'`, and `'68%'` placeholders. Analytics KPI row derives from real synchronized state.
- **No Mock Fallbacks**: API client failure handlers throw explicit `CareerPredictionError` / `ProjectRecommendationError` rather than returning synthetic mock records.
- **Deterministic Formulas**:
  - Competency Coverage: $\frac{|\text{Acquired} \cap \text{Core}|}{|\text{Core}|} \times 100$
  - Project Relevance: $\frac{|\text{Missing Core}| \times 2.0 + |\text{Missing Secondary}| \times 1.0}{\text{Total Target Skills}}$
  - Portfolio Evidence Coverage: $\frac{|\text{Competencies Verified by Deliverables}|}{|\text{Target Career Skills}|} \times 100$

## 10. Security Audit

- **CORS Configuration**: Wildcard origins (`*`) are strictly prohibited in code and rejected at configuration parse time. Origins are loaded from `ALLOWED_ORIGINS` / `CORS_ORIGINS`.
- **Request Boundary Limits**:
  - Maximum skill list length: 100 tokens.
  - Maximum individual skill string length: 100 characters.
  - Excessive requests rejected with HTTP 422.
- **Exception Sanitization**: `error_handler.py` catches all unexpected exceptions and returns generic JSON envelopes (`{"code": "server_error", "message": "An unexpected error occurred."}`). Internal filesystem paths and tracebacks are never exposed to the client.
- **No Committed Secrets**: `.env` is ignored by `.gitignore`. `JWT_SECRET_KEY` uses safe development defaults and `.env.example` provides explicit instructions for secure random key generation.

## 18. Academic Limitations

1. **Benchmark Size Constraint**: The model was trained on $N = 192$ structured engineering student records. It serves as an exploratory benchmark rather than a population-wide census.
2. **Minority Class Sparsity**: The `Cloud, DevOps & Systems Engineering` class has only 15 training and 4 holdout samples, causing argmax classification to require high prior evidence.
3. **Binary Feature Space**: The model operates on binary skill presence without measuring skill depth or recency.
4. **Correlation vs Causality**: Model feature attributions represent historical curriculum associations, not causal guarantees of job placement.

---

## 19. Ethical Considerations

1. **Exploratory Guidance Only**: The platform is explicitly labeled as an advisory curriculum guidance tool. It must never be used for employment gating or candidate rejection.
2. **Human Autonomy**: Students retain complete agency through target track overrides. The system never forces an algorithmic recommendation.
3. **Data Privacy**: No student data is transmitted to commercial third-party LLMs. All inference executes locally on dedicated application servers.
